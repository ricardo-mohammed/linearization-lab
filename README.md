# OD600 Regression Transformation

Extract the ZIP. Open OD600_Regression_Transformation.ipynb in VS Code or Jupyter and keep the Excel file beside it. Select your Python kernel. Install missing packages with pip install -r requirements.txt. Run cells from top to bottom.

Default analysis: well E12, 3–6 hours. Review the full curve before changing the well or time window. The supplied text is example code, not a separate assignment rubric; check any additional professor requirements.

Verified calculation results: direct regression test RMSE 0.04277, R² 0.67586; log-target regression test RMSE 0.00577, R² 0.99409. These are exploratory within-window results. Notebook outputs regenerate when run.
